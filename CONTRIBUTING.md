# Contributing

Contribute only code and documentation that you created or are authorized to share.

Before opening a pull request:

- Read LICENSE_SCOPE.md and THIRD_PARTY_NOTICES.md. The MIT license covers only the original code and documentation listed in the scope.
- Identify any third-party material, its source, and its license. Do not copy vendor pages, private work material, logos, images, fonts, or datasets without permission and attribution.
- Use synthetic values. Do not submit customer, personal, account, transaction, financial, employer, or production data.
- Remove credentials, private URLs, logs, and local exports before submitting.
- Report accidental exposure privately using the guidance in SECURITY.md; do not include the exposed material in a public issue.

By submitting a contribution, you confirm that you have the right to share it under the repository's stated license.
