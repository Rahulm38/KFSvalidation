# Security and privacy reports

Do not put credentials, private datasets, customer information, or exploit details in a public issue or pull request.

Use GitHub's private vulnerability reporting for this repository if it is enabled. If it is unavailable, contact the repository owner through the contact option on the Rahulm38 GitHub profile. Share a minimal reproduction that uses synthetic values.

For accidentally committed sensitive material, report the affected repository and path privately. Deleting a file in a later commit does not remove it from Git history.
