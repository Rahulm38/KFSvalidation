# Privacy

This is a static browser-only demo. The current application code has no project-owned account system, upload server, analytics, or API call. Inputs and calculations run in the browser, and the user chooses whether to download or print a generated statement. Use synthetic values only; do not enter or publish real personal, customer, account, transaction, financial, or production data.

The page loads Inter from Google Fonts. The browser contacts Google's font services to load it. See [Google Fonts technical considerations](https://developers.google.com/fonts/docs/technical_considerations) and [Google's privacy policy](https://policies.google.com/privacy).

GitHub says it logs and stores visitor IP addresses for security purposes when its Pages sites are visited. See [GitHub Pages data collection](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) and [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). These are GitHub's hosting logs; the project owner does not receive the visitor log from the page.

The repository and its issues are public. Do not publish personal or confidential information in issues or pull requests. See SECURITY.md for private reporting guidance.
